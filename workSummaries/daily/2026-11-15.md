## Lessons

- **Rebasing under PS-2.** Rebasing a PR branch would have needed a force-push, which PS-2 forbids. Instead:
  reset to the remote head, merge `origin/main`, resolve conflicts, and push normally.
- **Typed-ahead input in operator scripts.** A `[y/N]` prompt that follows a slow step (signing, pushing) can
  read keys typed early. Each confirm fails closed, so nothing went wrong. A resume script has to start from the
  state already reached and never re-sign.
