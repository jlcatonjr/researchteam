## Remediation of the API-reference findings

Plan: `tmp/by-week/2026-W43/api-doc-findings-remediation.plan.md`. Draft 1 was audited by `@adversarial`
(CONDITIONAL; six of eight items needed revision). Draft 2 was implemented, and all steps are done.

- **R1 `init --ref <commit>`:** a 7–40 hex ref falls back to the commit archive, and `.researchteam` records the
  full SHA. Fetch errors are a `RuntimeError`, which `init` turns into exit 1, and `is_safe_ref` rejects `..`.
- **R2 `init`:** the archive is downloaded and checked before the directory is created. An absolute or `..`
  member refuses the whole archive, extraction is confined to the target, and a later failure names the
  incomplete project.
- **R3 marker reader:** `read_marker` is the one reader for `ref`, `layer1` and `is_upstream`. First occurrence
  wins, a trailing comment is dropped, and quotes are stripped. `update` refuses an unsafe ref, and every ref
  check uses `is_safe_ref`.
- **R4 provenance:** a VCS install passes only from `jlcatonjr/agentteams`. Fork, archive and index installs need
  `RESEARCHTEAM_ALLOW_UNVERIFIED_AGENTTEAMS=1`.
- **R5 `library-query -k`:** the flag is parsed by position, and usage errors exit 2.
- **R6:** the Zelda-only bridge commands `open-reader` and `open-summary` are removed.
- **R7:** the certifi exception stays open. Re-vet on or after 2026-11-03.

  `fix/docs-mkdocs-material-9.7.7` in `../agentteams-wt-docs-mkdocs-material` pins mkdocs-material 9.7.7 and
  pymdown-extensions 12.1. It is not pushed.

    bridge commands against the bridge reference.
- **Tests:** a `conftest.py` keeps every test off the real GitHub API.
- **Results:** Python 3.14 478 passed, 1 skipped; Python 3.10 473 passed, 3 skipped. The strict build is clean,
