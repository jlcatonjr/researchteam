# R2 adversarial audit: tools, standards and field guides (Part II)

Round 2 of the 2-fold citation and claim audit. Independent of round 1: no file under `references/evidence/`
was read. Scope: `01-literature-review.md` sections 7 to 10, `02-analysis.md` sections 2, 3 and 5, and
`03-conclusion.md`, with their reference lists. Retrieved 2026-11-16.

Method. Each cited page was fetched with `curl -sL` and a generic User-Agent, the HTML was stripped to text
(tags removed, entities and curly quotes normalised, whitespace collapsed), and each quotation was searched
as a fixed string. "curl" in the table means that method. Obsidian's help site is rendered by JavaScript, so
its source Markdown was fetched with curl from the `obsidianmd/obsidian-help` GitHub repository. WebFetch
was not used. WebSearch was used only to find counter-examples, and every counter-example named below was
then read with curl from its own README or documentation.

Verdicts. Quotations: FOUND VERBATIM / FOUND WITH DIFFERENCES / NOT FOUND / CONTRADICTED. Claims: SUPPORTED /
OVERSTATED / UNSUPPORTED / CONTRADICTED. Dates and URLs: CONFIRMED / DIFFERS. "FOUND VERBATIM" ignores
markup, whitespace, the case of a first letter, and single versus double quotation marks.
