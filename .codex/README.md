# Codex Harness

`.codex/agents/*.toml` are OpenAI Codex custom agents **generated by agentteams**. Do not hand-edit
them. Codex is orchestrator-only (release policy section 5): `brief.json` sets
`write_policy: "orchestrator-only"` with `codex` in `write_policy_frameworks`, and
`researchteam update` / `researchteam materialize` render Codex natively from the brief. Since
agentteams #210 the old projection of `.github/agents` is refused for narrow-grant agents, and
researchteam no longer runs it. See *Codex is orchestrator-only* in
`docs/researchteam-framework.md`.

Codex skills (`.agents/skills/<name>/SKILL.md`) are still imported from the Claude skills:

```bash
agentteams --interop-from .claude/agents --interop-source-framework claude --framework codex \
  --interop-skills-only --output . --overwrite --yes
```

`--overwrite` is required. Without it, interop **skips files that already exist**, so an
already-imported skill never picks up later changes.

- Codex loads only `.codex/agents/**/*.toml`; the `name` key inside each file is authoritative.
- The orchestrator-only switch holds only when Codex is launched through
  `.codex/confined-run.example.sh`, whose launcher turns on the role gate.
- The repo-root `AGENTS.md` is shared with the Goose bridge; the Codex adapter never overwrites it.
