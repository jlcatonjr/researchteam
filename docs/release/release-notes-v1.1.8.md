Release on `release/1.1`. Still pins agentteams v1.1.4 (b82d78e7). **Autosync (#182):** the gate, which runs integrated agentteams and researchteam code, now runs in a job with `contents: read`; a separate job, which runs no integrated code, checks the gate's patch, decides the `security-review-required` label itself and opens the evergreen PR. The workflow uses two more pinned actions (`actions/upload-artifact` v7.0.2, `actions/download-artifact` v8.0.2). **Term register and term index (new feature in this release):** each project can keep coded definitions in `Projects/<project>/terminology/terms.json`; `term-build` indexes every occurrence, `term-check` is the gate, and `validate` runs it when a register exists. A repository with no register is unaffected. Optional Claude Code hooks keep the index in sync; `researchteam doctor` reports the state; `researchteam workflow-sync --workflow validate` installs an opt-in, read-only CI workflow. On 1.1.x the term index takes bug fixes only; its generic core is planned to move to agentteams 1.3. Derived repos move with `researchteam update --ref v1.1.8`, then `python3 scripts/check_toolchain.py --write-lock --tag researchteam=v1.1.8 --tag agentteams=v1.1.4`, then `researchteam workflow-sync` with the repository's own `@security` review.
