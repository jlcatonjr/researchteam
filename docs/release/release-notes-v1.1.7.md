Patch release. Still pins agentteams v1.1.4 (b82d78e7). The derived autosync workflow scaffold now ships with its weekly schedule commented out, so turning autosync on is a deliberate edit in each repository (#186). New command `researchteam workflow-sync [--yes] [--dry-run]` updates an existing repository's `.github/workflows/agentteams-sync.yml` from the installed scaffold and keeps that repository's own `on:` block, so a repository's schedule stays as it is. It shows a diff and asks before writing. Do not copy the scaffold over the workflow by hand. Derived repos move with `researchteam update --ref v1.1.7`, then `python3 scripts/check_toolchain.py --write-lock --tag researchteam=v1.1.7 --tag agentteams=v1.1.4`, then `researchteam workflow-sync` with the repository's own `@security` review.
