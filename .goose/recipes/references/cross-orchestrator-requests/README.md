# Cross-Orchestrator Requests

This directory stores coordination request artifacts exchanged between ResearchTeam and adjacent repository orchestrators.

Naming convention:
- `YYYY-MM-DD-<adjacent-repo>-<topic>.md`

Ownership:
- Created by `@repo-liaison`
- Reviewed by `@orchestrator` and `@conflict-auditor` when required

Notes:
- Keep request artifacts append-only for audit traceability.
- Do not store secrets or credentials in coordination artifacts.
